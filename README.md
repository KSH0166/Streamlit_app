# 🔊 Multilingual TTS App

A simple **Text-to-Speech (TTS)** application built with Streamlit.

This app converts written text into spoken audio in multiple languages. It demonstrates two approaches to building a TTS application.

## Features

- **Streamlit TTS:** Generate speech using Python and gTTS.
- **HTML TTS:** Generate speech using HTML, JavaScript, and the Web Speech API.
- Supports 9 language options.
- Listen to generated audio and download MP3 files (Streamlit version).

## Repository Files

| File | Description |
|---|---|
| `app.py` | Main Streamlit application |
| `tts.html` | HTML and JavaScript TTS application |
| `requirements.txt` | Required Python packages |
| `README.md` | Project information and documentation |

## Requirements

The `requirements.txt` file contains:

```text
streamlit
gTTS
```

## Technologies

- Python
- Streamlit
- gTTS (Google Text-to-Speech)
- HTML, JavaScript, Web Speech API


## Purpose

This sample project demonstrates how to organize a GitHub repository, document an application using `README.md`, and deploy a Python application using Streamlit.
